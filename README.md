# 🎬 MovieLand

MovieLand is a simple React app that allows users to search for movies using the [OMDb API](http://www.omdbapi.com/). It initially loads a list of Batman-related movies and allows users to search for others interactively.

---

## 📦 Features

- 🎥 Search for movies by title
- 🔍 User input-driven search functionality
- 🧠 Initial search preloads Batman movies
- 📄 Displays movie cards with poster, title, and year
- ❌ Graceful fallback when no movies are found
